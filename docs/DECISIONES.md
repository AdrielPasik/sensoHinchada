# Decisiones y consultas

## Aceptadas para Fase 1

1. **Modo DEMO local:** evita presentar números inventados como reales mientras no exista backend autorizado.
2. **Sin escudos:** se usan colores y monogramas originales para evitar licencias sin verificar.
3. **Sin DNI:** el flag de identidad queda apagado y no existe campo de captura.

## Para confirmar antes de Fase 2

1. **Marca visible:** recomendamos mantener provisionalmente “Senso Hinchada”, con el repositorio `sensoHinchada` sin cambios.
2. **Una selección global:** recomendamos un solo club favorito por cuenta; separar argentino/internacional duplica modelo y ranking.
3. **Edición de club:** recomendamos no habilitar cambios arbitrarios al lanzamiento; definir una revisión excepcional o período de espera.
4. **Datos personales:** recomendamos no pedir nombre/apellido en MVP hasta justificarlo y revisar el flujo legal.
5. **Privacidad:** recomendamos iniciar con 20 participaciones por localidad y suprimir categorías con menos de 5.
